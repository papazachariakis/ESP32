    Έλεγχος γεννήτριας

    Απομακρυσμένος έλεγχος μέσω MQTT Modbus. Χρησιμοποίησε με προσοχή.

    Ρυθμίσεις Modbus (απομακρυσμένα)

    Πρέπει να ταιριάζουν με τον PS0600. Αποθηκεύονται στο ESP32 και επιβιώνουν reboot.

    Probe register: δέξου 4xxxx (π.χ. 40009) ή γυμνή διεύθυνση (π.χ. 8, 9). Loopback: ένωσε TX2-RX2 ή TXD-RXD.

    Επαφές / Relays
    ESP32 → XY-485 → PS0600 (Cummins C22D5)

    Modbus RTU 8N1 • GPIO16=RX2, GPIO17=TX2 • DE/RE δεν χρησιμοποιείται (auto-direction XY-485)
    TX/RX σταυρωτά: TX2→RXD, RX2→TXD (τα labels TXD/RXD είναι από την πλευρά του module)

    Troubleshooting
    • Αν βλέπεις modbus 40009: πρώτα σταύρωσε TX/RX (TX2→RXD, RX2→TXD) — όχι TX→TXD
    • Μετά, αν χρειάζεται: αντάλλαξε A↔B
    • Έλεγξε slave ID και baud (συνήθως 9600 ή 19200, 8N1) στο μενού PS0600
    • Για μακρύ καλώδιο (>10m): termination 120Ω στα άκρα
    • Μην συνδέσεις DE/RE — το module είναι auto-direction
